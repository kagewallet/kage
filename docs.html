Everything you need to run KAGE: install it, create or restore a wallet, receive and send on Robinhood Chain, pick your RPC, and understand exactly who holds what.

一 Install

KAGE v0.1.0 is a web app — nothing to install. Open kagewallet.app/app in your browser and you are in. Keys are generated and stored in that browser only. A downloadable macOS build comes next.

注

Early software. Start with a small amount while v0.1.x matures, and only download KAGE from this site or the official GitHub releases.

二 Create or restore a wallet

Create

  1. Open KAGE and choose Create wallet.
  2. Write down the 24-word seed on paper, in order. This seed is the wallet — anyone who has it has your coins.
  3. Set a password. It locks the wallet file on this device only.

Restore

  1. Choose Restore wallet and type your 24 words.
  2. Set a new password for the new device.
刀

KAGE has no account and no server login. Lose the seed and the password together, and no one — including us — can bring the wallet back.

三 Receive

Open the Receive tab. Your address works for both ETH and USDG on Robinhood Chain. Share it as text or as a QR code; balances update live as transfers confirm.

四 Send

  1. Paste the recipient address — KAGE checks the format before anything else.
  2. Enter the amount (ETH or USDG).
  3. Review the confirmation sheet: amount, gas, and total. Gas on Robinhood Chain runs near 0.01 gwei, so the fee is close to nothing.
  4. Send. The transaction hash stays in your activity list, linked to the explorer.

五 Network & RPC

KAGE talks to the RPC endpoint you choose, and you can change it at any time in Settings → Network.

六 Bridge

From the receive page you can bridge ETH in from Ethereum mainnet and arrive on Robinhood Chain in minutes. You get a live quote first, every step is tracked, and a refund address protects the transfer. Bridging back out ships next.

七 Security model

  • Keys: generated and stored on your device, encrypted with your password. They never leave it.
  • Cryptography: audited, standard Ethereum libraries — nothing home-rolled.
  • Servers: none. No account, no login, no custody. The only network traffic is to the RPC you chose.
  • Code: public on GitHub. Read it, build it, verify it.
