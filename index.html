QUESTIONS — 問答

Straight answers.
No fine print.

01Can I use KAGE today?+

Yes — right in your browser. The v0.1.0 web app runs on the Robinhood Chain mainnet with real ETH, straight from kagewallet.app/app. It is early software — start with a small amount. A macOS build comes next.

02Who holds my keys?+

You do. Your seed and keys stay on your device, locked with your password. KAGE has no account and no server login, so no one can see your keys, move your coins, or restore your wallet.

03Does KAGE write its own cryptography?+

No. KAGE uses audited, standard Ethereum libraries for keys, addresses, and transactions — nothing home-rolled.

04Is the code public?+

Yes. The code is on GitHub, so anyone can read it and build it.

05Is KAGE affiliated with Robinhood?+

No. KAGE is independent software that speaks to Robinhood Chain. Robinhood does not endorse it.
